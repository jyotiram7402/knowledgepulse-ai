# Environment Variables Reference

## Backend (Render)

| Variable                  | Required | Default                                                  | Notes                                                   |
| ------------------------- | -------- | -------------------------------------------------------- | ------------------------------------------------------- |
| `SPRING_PROFILES_ACTIVE`  | no       | `prod`                                                   |                                                         |
| `PORT`                    | no       | `8080`                                                   | Render injects this automatically                       |
| `DATABASE_URL`            | yes      | -                                                        | JDBC URL from Neon (`jdbc:postgresql://...`)            |
| `DATABASE_USERNAME`       | yes      | -                                                        | Neon username                                           |
| `DATABASE_PASSWORD`       | yes      | -                                                        | Neon password                                           |
| `JWT_SECRET`              | yes      | generated by Render                                      | At least 32 bytes; HS256                                |
| `JWT_EXPIRATION_MS`       | no       | `86400000`                                               | Token TTL in milliseconds                               |
| `GEMINI_API_KEY`          | yes      | -                                                        | Google AI Studio                                        |
| `GEMINI_CHAT_MODEL`       | no       | `gemini-1.5-flash`                                       |                                                         |
| `GEMINI_EMBEDDING_MODEL`  | no       | `text-embedding-004`                                     | Returns 768-dim vectors                                 |
| `CLOUDINARY_CLOUD_NAME`   | yes      | -                                                        |                                                         |
| `CLOUDINARY_API_KEY`      | yes      | -                                                        |                                                         |
| `CLOUDINARY_API_SECRET`   | yes      | -                                                        |                                                         |
| `CORS_ALLOWED_ORIGINS`    | yes      | `http://localhost:5173`                                  | Comma-separated origins                                 |
| `ADMIN_EMAIL`             | yes      | -                                                        | Seed admin login                                        |
| `ADMIN_PASSWORD`          | yes      | -                                                        | Seed admin password (>= 8 chars)                        |

## Frontend (Vercel)

| Variable        | Required | Notes                                                      |
| --------------- | -------- | ---------------------------------------------------------- |
| `VITE_API_URL`  | yes      | Full base URL of the backend, e.g. `https://kp.onrender.com/api/v1` |
